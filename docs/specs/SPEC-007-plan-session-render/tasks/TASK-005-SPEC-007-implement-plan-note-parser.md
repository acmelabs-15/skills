# TASK-005-SPEC-007: Implement PlanNote Parser

## Design Context

This TASK realizes REQ-004-SPEC-007 and the parsers/plan-note.ts from ANALYSIS-002 Appendix D.

## Objective

Create `_shared/composition/src/parsers/plan-note.ts` implementing parsePlanNote with all section parsers: parseScope, parseObjectives, parsePartsSection (with parsePart, derivePhaseFromId, parseDodFromPart, parseDecisionsTable), parseTasksSection (with Active/Backlog/Archive sub-tables), parsePendingDecisions, parseEditorMirror, parseBlockers, parseObservations, parseRelations. Skip derived sections (Progress Dashboard, Cross-Part Dependency Graph).

## Scope

**In Scope**:

- parsePlanNote main function with unified pipeline
- All section-specific parser functions
- Phase derivation from part id
- Session wikilink stripping to SessionIdSchema format
- Outcome parsing (wikilink vs file)
- Skipping derived H2 sections

**Out of Scope**:

- Session parser (TASK-006)
- Renderer implementation
